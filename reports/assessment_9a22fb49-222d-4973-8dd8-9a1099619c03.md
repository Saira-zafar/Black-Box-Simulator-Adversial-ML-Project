## 3. Defensive Remediation Guidance

### Broken Object Level Authorization (BOLA / IDOR) Remediation:
Enforce authorization checks at the data layer for every object retrieval. Check whether `current_user.id == resource.owner_id` (or user possesses explicit tenant role). Return HTTP 403 Forbidden or 404 Not Found if access is not permitted.
